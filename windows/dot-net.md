# DotNet


---
## Uses

1.  Navigate to the project folder (not the solution folder) and run

```powershell
dotnet run
```

or from anywhere, point it at the project file:

```powershell
dotnet run --project path/to/YourProject.csproj
```

2. If you just want to build without running:

```powershell
dotnet build
```

3. For a specific configuration (like Release):

```powershell
dotnet run --configuration Release
```
